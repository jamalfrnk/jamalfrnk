## Flagship Project: Solana Vault Prototype

A security-tested Solana vault program built with Rust and Anchor, supported by a TypeScript SDK and a minimal Next.js dApp.

### What it demonstrates

* PDA-controlled SPL token custody
* Safe token transfers through CPI
* Deposit and withdrawal accounting
* Governance and emergency controls
* Two-step authority rotation
* Mint exposure limits
* Exit-first pause behavior
* Account migration and versioning
* Adversarial and negative-path testing
* Devnet deployment and verification
* Test-driven development and gated CI

### Verification

* 97 Rust tests
* 117 TypeScript SDK tests
* 122 dApp tests
* Automated formatting, build, Clippy, test and audit checks
* Reproducible Codespaces development environment
* Architecture decision records, security checklist, runbook and interview walkthrough

The project is intentionally documented as an educational, pre-audit prototype rather than an audited or mainnet-ready custody product.
